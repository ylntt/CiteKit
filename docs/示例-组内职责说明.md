# 数据平台组 · 职责与技能说明（脱敏示例）

> 本文件是脱敏示例，用于验证检索与「出处」功能，不含任何真实内部信息。

## 一、组内职责

1. 维护数据接入链路，保证每日数据按时产出。
2. 维护指标口径文档，口径变更需同步通知下游。
3. 为业务方提供取数支持与数据答疑。
4. 负责数据质量监控与异常告警的响应。

## 二、岗位技能要求

- 必备：SQL、Python 基础、Linux 常用命令。
- 必备：能读懂指标定义，理解口径变更的影响范围。
- 加分：了解向量检索与 RAG 基本流程。
- 加分：能写自动化脚本减少重复取数。

## 三、常见流程

- **需求评审**：业务方提出取数需求 → 组内评估口径 → 确认交付时间。
- **口径变更**：先更新口径文档 → 通知下游 → 再改代码。
- **上线**：代码评审通过 → 灰度 → 观察一日数据 → 全量。

## 四、常见问题

- **数据延迟怎么办**：先看上游任务是否失败，再看调度队列是否排队。
- **口径不一致怎么办**：以口径文档最新版本为准，历史报表需标注口径版本。
- **新人如何上手**：先读本文件，再跟一次完整的取数需求流程。
